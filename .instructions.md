# ISO Certifications Laravel Project

## Project Overview
A Laravel 13.8.0 web application for managing ISO certifications. Built with PHP 8.4.7 and MariaDB database.

## Tech Stack
- **Framework**: Laravel 13.8.0
- **PHP Version**: 8.4.7
- **Database**: MariaDB 12.2.2
- **Frontend**: Blade templates with Tailwind CSS
- **Build Tool**: Vite
- **Testing**: PHPUnit 12.5.24

## Database Configuration
- **Database Name**: laravel
- **Host**: 127.0.0.1
- **Port**: 3306
- **Username**: laravel
- **Password**: password
- **Connection**: MySQL via TCP

## Project Structure
```
iso-certifications/
├── app/                 # Application code (Models, Controllers, Services)
├── config/             # Configuration files
├── database/           # Migrations and seeders
│   └── migrations/    # Database schema files
├── resources/          # Views and assets
│   └── views/         # Blade templates
├── routes/            # Web and API routes
├── storage/           # Application storage (logs, cache)
├── tests/             # Test files
├── public/            # Web root (CSS, JS, images)
├── bootstrap/         # Application bootstrap
├── artisan            # Laravel CLI tool
├── composer.json      # PHP dependencies
├── package.json       # Node.js dependencies
├── .env               # Environment configuration
└── vite.config.js     # Vite build config
```

## Database Tables
- `users` - User accounts
- `migrations` - Migration tracking
- `cache` - Application cache
- `cache_locks` - Cache locking mechanism
- `jobs` - Queue jobs
- `job_batches` - Batch job tracking
- `failed_jobs` - Failed job records
- `password_reset_tokens` - Password reset tokens
- `sessions` - User sessions

## Development Server
**URL**: http://localhost:8000
**Command**: `php artisan serve --port 8000`

## Key Commands
```bash
# Start development server
php artisan serve

# Interactive shell (Tinker)
php artisan tinker

# Database operations
php artisan migrate              # Run migrations
php artisan migrate:reset        # Reset database
php artisan make:migration name  # Create migration

# Code generation
php artisan make:model Model -m  # Create model with migration
php artisan make:controller ControllerName
php artisan make:seeder SeederName

# Testing
./vendor/bin/phpunit

# Code formatting
./vendor/bin/pint
```

## Environment Variables
- `APP_ENV=local` - Development environment
- `APP_DEBUG=true` - Debug mode enabled
- `DB_CONNECTION=mysql` - Database driver
- `SESSION_DRIVER=database` - Session storage in database
- `QUEUE_CONNECTION=database` - Queue uses database

## Important Files
- `.env` - Local environment configuration (DO NOT commit)
- `.env.example` - Environment template
- `routes/web.php` - Web routes definition
- `resources/views/` - Blade view templates
- `app/Http/Controllers/` - HTTP controllers
- `database/migrations/` - Database schemas

## Development Workflow
1. Create feature branch
2. Update migrations if needed: `php artisan make:migration`
3. Update models: `php artisan make:model`
4. Create routes in `routes/web.php`
5. Implement controllers in `app/Http/Controllers/`
6. Create views in `resources/views/`
7. Test with `php artisan tinker` or PHPUnit
8. Run `./vendor/bin/pint` for code formatting

## Database Browser Options
- **Laravel Tinker**: `php artisan tinker` (built-in)
- **TablePlus**: Download from App Store or `brew install tableplus`
- **DBeaver**: Download from web (use MariaDB driver)
- **Command Line**: `mariadb -u laravel -ppassword laravel`
